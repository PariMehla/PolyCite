# PolyCite v1 — Multilingual RAG failure attribution on Cohere

## Goal
Measure where multilingual RAG breaks across 8 languages (eng_Latn, fra_Latn,
zho_Hans, arb_Arab, hin_Deva, ben_Beng, swh_Latn, yor_Latn) using Belebele
(facebook/belebele) as a parallel benchmark. Conditions: MONO, X->EN, EN->X, MIXED.

## HARD RULES
- Cohere trial key: 1,000 calls/month TOTAL. Every Cohere call goes through
  `polycite/cohere_client.py`, which (1) checks a persistent call counter in
  `cache/call_count.json` and refuses to exceed BUDGET, (2) caches every response
  on disk keyed by sha256(endpoint + model + params + input), (3) rate-limits per
  endpoint (chat 20/min, embed 100/min, rerank 10/min) with exponential backoff
  on 429.
- Before any batch job, `estimate_and_confirm()` prints the number of calls it
  will make and requires explicit confirmation (env `POLYCITE_AUTO_CONFIRM=1`
  or an interactive `y`) before spending a single call.
- Never call Cohere in tests; mock `CohereClient` or use `FakeTransport`.
- Batch embed calls at the max texts per call (96).
- Use `input_type="search_document"` for passages, `"search_query"` for queries.
- Temperature 0. Log model name and version string in every result row.

## Known environment constraint (read this first)
This repo was scaffolded inside a sandboxed session with no egress to
`huggingface.co` or `api.cohere.com`. All pipeline code is real and unit
tested against synthetic fixtures (`polycite/data/fixtures.py`), but nobody
has run it against the live Belebele dataset or a live Cohere key yet. The
first person who does (with `COHERE_API_KEY` set and normal internet) should
treat `make reproduce FULL=1` as the real first run, sanity check the schema
per `data/belebele.py`'s inspection step, and expect to find and fix small
surprises (see "First real run checklist" in README.md).

## Metrics
Retrieval: Recall@1/5/20, MRR@10 (gold = question's Belebele passage).
Generation (deterministic only in v1, no LLM judge yet): option accuracy,
citation precision/recall vs gold passage ID, abstention rate.
Bootstrap 95% CIs (10k resamples) on everything reported.
Attribution per failure, in order: retrieval miss > rerank miss > reading
error > citation error > language error > hallucinated confidence.

## Style
Small functions, type hints, pytest for every metric function. No comments
that restate what the code does — only ones that explain a non-obvious why
(e.g. CJK tokenization, FLORES/MIRACL style mismatch).
